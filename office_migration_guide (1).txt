================================================================
INTERACTIVITY ENHANCEMENTS (Driver + Heatmap)
================================================================
Added after the polish pass:

1. TOOLTIP FIX — the hover tooltip is rendered via React PORTAL
   into document.body (createPortal), so it escapes the "view-in"
   container's transform. Any transformed ancestor breaks
   position:fixed, which made the tooltip stick to the bottom.
   Portal + zIndex:9999 fixes it. Applies to BOTH DriverView and
   HeatmapView. The Driver feature popup modal is also portaled.
   (Requires: import { createPortal } from 'react-dom';)

2. CLICKABLE KPI CARDS — KPIs now flip on click. Front = number + %.
   Back = a CROSS-MARKET fact, e.g. "At 12.6%, Vodafone UK is 2.1 pts
   above the cross-market average — rank 1 of 3." Computed, not invented.

3. FEATURE CLICK POPUP (Driver) — clicking a factor name opens a
   centered modal (dim backdrop) with "What it is" + "What it means
   here". Click backdrop or × to close. Hover still shows quick tooltip.

  - pass allMarketKpis + market to DriverView AND HeatmapView
